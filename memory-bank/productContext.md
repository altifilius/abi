# Product Context

- Problem: founders struggle to map R&D ideas to the right Turkish grants, draft compliant summaries, and keep documents/incorporation tasks organized.
- Users need: quick eligibility signal, AI help crafting a TÜBİTAK/KOSGEB-ready narrative, and a clear checklist of filings/documents.
- Experience goals: conversational guidance first; minimal manual forms; glassy, futuristic UI with clear status chips and checklists; fast iteration from chat → summary → fund matches → docs.
- Current flows: (1) AI Coach chat produces a 1-pager; (2) Fund Matcher scores the description vs known funds and explains why; (3) Document checklist tracks uploads/verification; (4) Incorporation guide lists steps and deadlines.
- Non-goals (now): real submission filing, multi-user collaboration, auth, and persistent storage.
