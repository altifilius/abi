# Product Context

- Problem: founders struggle to map R&D ideas to the right Turkish grants, draft compliant summaries, and keep documents/incorporation tasks organized.
- Users need: quick eligibility signal, AI help crafting a TÜBİTAK/KOSGEB-ready narrative, and a clear checklist of filings/documents.
- Experience goals: only My projects / Find support in top navigation; premium calm card-based project file, idea-first onboarding, and conversational report writing rather than admin screens. Scope/country require user review; hidden complexity remains accessible contextually.
- Current flow: direct idea chat → reviewed scope/country → project file → predefined reports written section-by-section in isolated conversations → saved rich documents/exports; multiple sourced funding preparations grouped separately. New sections/reports can be opened before previous ones are complete; AI only applies saved drafts on explicit instruction. Discovery is project-country relative and never invents eligibility.
- Non-goals: automatic portal submission, claims of legal eligibility or funding probability, real checkout and unconfigured payment/price/OCR quota rules. Authentication, persistence and bounded team collaboration are implemented product scope.
